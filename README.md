# Burhani H. Katimba — Portfolio

A responsive portfolio for GitHub Pages, styled from the Canva slide references with an ivory and deep-green palette, editorial serif typography, and photo-led sections.

`index.html` is the GitHub Pages entry point. `index.original.html` is kept in sync for local editing. Images are stored under `assets/`.

## Publish with GitHub Pages

1. Authenticate to GitHub with GitHub CLI or Git Credential Manager.
2. Push this folder to a public repository under `burhanikatimba`.
3. In repository settings, open **Pages** and choose **Deploy from a branch**, branch **main**, folder **/(root)**.

A project repository named `portfolio` will be served at `https://burhanikatimba.github.io/portfolio/`. A repository named `burhanikatimba.github.io` will be served at `https://burhanikatimba.github.io/`.
